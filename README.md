# Gunjan Digital Studio

This project uses an Express backend and a static HTML, CSS, and JavaScript frontend. The backend serves both the website and its API.

## Deploy the frontend on Render

The root `render.yaml` configures a Render Static Site that publishes only `frontend/`, skips dependency installation, and preserves the UI files. Follow [the static deployment guide](docs/render-static.md) for Blueprint or manual setup. A separate backend is still needed for `/api/...` features; do not put database credentials in the static site's environment variables.

## Run locally

Open a terminal in the project root, where this README and `package.json` are located:

```powershell
npm.cmd install
npm.cmd run dev
```

Open http://localhost:5001. The port is configured in `backend/.env`. To run without automatic restarts, use `npm.cmd start`. Stop the server with Ctrl+C.

The root install script installs backend dependencies too. Use `npm.cmd` in PowerShell to avoid the blocked `npm.ps1` script.

## Configuration

The backend reads `backend/.env` when started through the root npm scripts. Its settings include `MONGO_URI`, `PORT`, `JWT_SECRET`, email settings, Twilio settings, and Razorpay settings. The root `.env.local` is preserved, but the current server does not load it.

If Atlas SRV lookups fail because the local DNS resolver refuses requests, set `MONGO_DNS_SERVERS=1.1.1.1,8.8.8.8` in `backend/.env`. The backend uses these optional resolvers for Node DNS lookups without changing Windows network settings. Leave this setting unset to use the default resolver.

If the configured MongoDB connection fails, the server attempts to start an in-memory database. Data stored there is temporary, and first startup may require downloading MongoDB. Payment, email, and SMS functionality require their respective service credentials.

The fallback MongoDB executable is cached in `backend/.cache/mongodb-binaries/`, configured in `backend/package.json`. This project cache avoids using the incomplete executable found in the Windows user cache. Cache files are ignored by Git. After a fresh checkout, the fallback downloads a suitable executable if needed; let that download and extraction finish before stopping startup.

The `frontend` npm script serves only static files on port 3001. Use `dev` or `start` for the website with its API.
